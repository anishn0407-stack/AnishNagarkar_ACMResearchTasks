# ACM Research Tasks

This repository contains my submissions for the ACM Research Tasks, covering Python-based email detection using regular expressions, a review of prompt engineering techniques, and a research paper summary.

## Tasks

- **Task 0:** Sneaky Log Tracker — detects and hides email addresses using Python Regular Expressions.
- **Task 1:** Prompt Engineering Techniques — review and analysis of various prompt engineering techniques.
- **Task 2:** Research Paper Summary — summary and key insights from a selected research paper.
